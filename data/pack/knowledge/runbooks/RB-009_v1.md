# RB-009 Failed remediation: rollback or escalate (version 1, current)

## Supported incident types
any; verification failed after an approved action

## Preconditions
An approved action was executed and the health verification did not pass.

## Investigation steps
1. Record the action result and the metrics after the action.
2. Decide whether the action is reversible: rollback, scale and configuration changes are, a restart is not.
3. Do not repeat the same action more than once.

## Approved remediation
Undo the action if it is reversible and made things worse. Otherwise escalate to the service owner with the full audit trail.

## Required permission
Engineer approval for any undo action

## Risks and side effects
Repeated actions can extend the outage.

## Rollback procedure
Use the rollback instructions of the failed action's runbook.

## Verification criteria
Metrics are back to the state before the action or better.

## Escalation
Always escalate when verification fails twice.
