# RB-004 High API latency investigation (version 1, current)

## Supported incident types
latency

## Preconditions
p95 latency is 1 second or higher.

## Investigation steps
1. Check the error rate and CPU to see whether latency is a symptom of another problem.
2. Inspect traces: find the slowest span and which service owns it.
3. Look for connection pool wait messages (then use RB-012), slow query logs, or cache hit ratio drops.
4. Check for a deployment or a configuration change just before the latency rose.

## Approved remediation
No single action. Choose the matching runbook: RB-012 for pool exhaustion, RB-007 for configuration changes, RB-001 for deployments, RB-006 for slow dependencies.

## Required permission
Not applicable

## Risks and side effects
Acting before the cause is known can hide the evidence.

## Rollback procedure
Not applicable.

## Verification criteria
p95 latency below 1 second for 5 minutes.

## Escalation
If no cause is found, escalate with the trace and metric evidence attached.
